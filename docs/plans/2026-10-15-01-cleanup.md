# Phase 1: Clean-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove code and documents left over from the Python era, and fix wrong on-screen text. The app should behave the same afterwards, apart from the corrected wording.

**Architecture:** Mostly deletions. Each task removes one group of dead code, then proves the app still builds and the tests still pass. One small testable helper is added for friendlier transform error messages.

**Tech Stack:** Swift 5, SwiftUI, Xcode project with hand-listed source files, XCTest.

**Spec:** `docs/plans/2026-10-15-00-improvement-roadmap.md`, findings D1–D4, F5, F6 and F11. Read that file's "Global constraints" first.

## Global Constraints

See the roadmap file. In particular, app source files are listed in `project.pbxproj`, so deleting one needs its lines removed there. The minimum macOS is 14.6. Use the build and test commands exactly as given there.

## Review Focus

This phase only removes code and changes wording. The risk is deleting something that is still used.
Every deletion task ends with a full build plus a `grep` that proves the removed names are gone.
No new runtime inputs are introduced.

````markdown
## How It Works

Rayee is a single native Swift app — no Python, no server.

- **Speech to text:** [WhisperKit](https://github.com/argmaxinc/WhisperKit) runs OpenAI's Whisper models on-device with Core ML.
- **Text transformations:** [mlx-swift-lm](https://github.com/ml-explore/mlx-swift-lm) runs a small language model on the Mac's GPU.
- Models download on first use and are stored in `~/.rayee`.

## Building from Source

### Prerequisites
- macOS 14.6+, Apple Silicon
- Xcode 16+ with the Metal Toolchain (`xcodebuild -downloadComponent MetalToolchain`)

### Build and run
```bash
open swift/Rayee/Rayee.xcodeproj
# Press Cmd+R in Xcode
````
